# 02: Valideer werkitems via de CLI

ID: `dda3ba02-3a0c-4001-82c2-3312897f23c8`

Status: `ready-for-agent`

Categorie: `planbaar-werk`

Prioriteit: `202`

**What to build:** Een maintainer kan een lokaal werkitem controleren voordat de queue het uitvoert. De CLI accepteert geldige metadata en geeft bruikbare fouten voor ontbrekende of tegenstrijdige gegevens.

**Blocked by:** 01: Start de TypeScript-CLI.

- [ ] Het formele werkitemschema bevat de persistent UUID, categorie, prioriteit, workflowstatus, goedkeuring, afhankelijkheden, acceptatiecriteria en runverwijzingen die de workflow nodig heeft.
- [ ] De validator controleert dat prioriteit bij de categorie hoort en uniek is onder open werkitems.
- [ ] Triage-statuswaarden blijven onderscheiden van de canonieke workflowstatus.
- [ ] Onbekende afhankelijkheden, afhankelijkheidscycli en ongeldige menselijke goedkeuringsgegevens worden als fouten gemeld.
- [ ] De CLI kan een representatief geldig en ongeldig lokaal werkitem valideren zonder externe service.
