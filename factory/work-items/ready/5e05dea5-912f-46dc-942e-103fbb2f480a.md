# 01: Start de TypeScript-CLI

ID: `5e05dea5-912f-46dc-942e-103fbb2f480a`

Status: `ready-for-agent`

Categorie: `planbaar-werk`

Prioriteit: `201`

**What to build:** Een maintainer kan de lokale factory-CLI vanaf een schone checkout starten. De TypeScript-runtime, package manager en minimale CLI-ingang zijn reproduceerbaar ingericht en de gekozen gebruikelijke commando's zijn gedocumenteerd.

**Blocked by:** None (can start immediately).

- [ ] De gekozen TypeScript-toolchain en versies zijn vastgelegd en reproduceerbaar.
- [ ] De CLI start vanuit een schone checkout en toont hulp of een equivalente gebruiksinstructie.
- [ ] De gekozen installatie-, ontwikkel- en controlecommando's staan in de project-README.
- [ ] Er zijn geen echte secrets of onnodige providerafhankelijkheden toegevoegd.
