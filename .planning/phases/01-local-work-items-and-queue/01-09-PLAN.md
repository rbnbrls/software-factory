## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent processes → lease file | A single kernel create decides the one writer |
| expired lease → new work | Silence must not be read as death |
| lease owner identity → PID check | Cross-host PIDs are meaningless |
